# 勇者塞满包 · 背包合成乱斗（Backpack Heroes: Stuff & Brawl）

基于 **《闯关勇者》** 原生解包立绘、全角色/怪物 **`_st.png` 挨揍颜艺差分帧**、高清装备与神器图集、`Bullets/` 飞弹切帧、`Hud/` 彩色位图伤害跳字、`fz.ttf` 字体及原声配乐打造的 **《Backpack Battles（背包乱斗）》/《袋中勇者》风竖屏 9:16 异形网格合成自走对战** 独立 Web 游戏。

## 核心特色玩法

1. **7×5 异形背包扩建与双模丝滑摆包**
   - 中心 `5×3 = 15` 格起步（竹仙·招财行商初始 `19` 格），每轮战斗结算后奖励 `+2 ~ +3` 点正交相邻扩建额度（满 35 格溢出自动折算金币）。
   - 涵盖 `1×1`、`1×2`、`2×1`、`1×3`、`2×2`、`L3(3格镂空)` 六类异形装备与 **90° 顺时针旋转**（快捷键 `R` 或中腰【🔄 旋转】按钮），搭配右侧 **4 格暂存托盘（Holding Tray）** 与【✨ 一键智能整理】。
   - 同时支持 **Pointer 按住拖拽实时绿/金/橙红预览落位** 与 **单指/鼠标点选放置** 双操作模式。
2. **双层合成体系（同名四阶进化 + 跨物品★神话神装）**
   - **同名二合一升阶**：剑、斧、弓、火铳、重锤、法杖 6 大武器系支持 `Lv1 → Lv2 → Lv3 → Lv4` 叠合原地进化，省出宝贵空间且战力跃升。
   - **6 组跨物品★神话觉醒**（支持手动拖拽融合，或十字正交紧贴摆放于开战瞬间自动觉醒）：
     - `魔法烤鸡腿 + 法杖(Lv1~3)` ＝ **★ 鸡腿法杖**
     - `生命星石/圣光神盾章 + 圣光塔盾/泰坦重铠` ＝ **★ 守护巨盾**
     - `幸运白喵 + 地精钱袋` ＝ **★ 招财神猫**
     - `先祖图腾 + 狂怒火种/精锻磨刀石` ＝ **★ 狂暴图腾**
     - `深渊剧毒瓶 + 荆棘刺戒` ＝ **★ 万毒魔戒**
     - `精密发条齿轮 + 秘银利剑/精灵自然弓(Lv2~3)` ＝ **★ 雷霆风剑**
3. **十字正交（4向）与八向星位（8向）邻接光环连线**
   - 发条齿轮、时间/生命/冰霜星石、精锻磨刀石、圣光神盾章、深渊剧毒瓶、腥红伯爵披风向周围装备投射实时可视化连线，提供充能加速（最快压至 `0.45s`）、暴击、增伤、叠盾倍增、附毒与吸血。
4. **上半屏 1v1 独立 CD 狂飙飞弹对轰 & `_st` 挨揍颜艺**
   - 开战后敌我双方每件装备按各自独立冷却进度条高频触发，跨屏抛射原版飞弹；受击瞬间实时切换 `_st.png` 挨揍颜艺立绘并弹出 `Hud/` 原版彩色位图数字跳字（`PT_` 普伤、`BJ_+boom` 暴击、`HX_+` 治疗、`ZD_-` 穿盾剧毒、`FS_` 护盾/荆棘反伤、`SB.png` 闪避），15 秒后进入疲劳狂暴直至决出胜负。

## 目录结构

```text
backpack/
├── SPEC.md                 # 全局架构、数学公式与 ES Module 接口契约
├── index.html              # 竖屏 9:16 四段式主舞台与原生 <dialog> 模态框
├── styles.css              # 响应式容器查询、网格底砖、光环连线与战中 CD 遮罩样式
├── wrangler.jsonc          # Cloudflare Workers 静态资源部署配置 (name: "backpack-yongzhe")
├── src/
│   ├── engine/
│   │   ├── prng.js         # 确定性 Mulberry32 伪随机数生成器
│   │   ├── catalog.js      # 4 勇者、10 轮递进 Boss、52 件装备与 6 组神话配方映射
│   │   ├── grid.js         # 7×5 旋转归一化、碰撞检测、扩建解锁、合成与光环计算引擎
│   │   ├── combat.js       # 逐帧 BattleSimulator 与无头高速 runHeadlessCombat
│   │   └── session.js      # 10 轮闯关状态机、商店/托盘/背包操作与启发式智能摆包 AI
│   ├── audio.js            # 原生 BGM 切换与节流 SFX 音频池
│   ├── fx_renderer.js      # 跨屏贝塞尔飞弹池与零断链 Hud 位图数字渲染器
│   └── main.js             # 双模拖拽/点选交互控制器与 60fps 实时战斗播放器
├── tests/
│   └── engine.test.mjs     # 全量资产校验、核心机制单测与 200 局无头 AI 平衡压测
└── tools/
    └── build_dist.mjs      # 构建自包含静态发布包 backpack/dist/
```

## 本地运行与独立发布包构建

构建自包含静态发布包 `backpack/dist/`（自动归集实际引用的 `237` 项原生美术/位图字/字体/音频资产，约 `13.98 MB`，自动重写 `./assets` 并附 `.nojekyll`）：

```bash
node backpack/tools/build_dist.mjs
```

在仓库根目录启动本地静态服务：

```bash
python3 -m http.server 8896
```

浏览器访问：
- 开发源码版：`http://127.0.0.1:8896/backpack/`
- 独立发布包：`http://127.0.0.1:8896/backpack/dist/`
